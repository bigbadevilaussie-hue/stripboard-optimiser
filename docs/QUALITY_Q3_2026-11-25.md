# Q3 construction quality — GUI 2.38

Approved recalibration of Q2: multiply the raw construction penalty by 0.4
before clipping and rounding.

```python
Q3 = round(max(0, 100 - 0.4*(0.6*W + 0.4*C + 0.02*L + 10*D + 15*U + max(0,S-1)**2)), 2)
```

| Penalty | Q2 | Q3 |
|---|---:|---:|
| Jumper W | 0.60 | 0.24 |
| Cut C | 0.40 | 0.16 |
| Wire length L, mm | 0.020 | 0.008 |
| Nonvertical jumper D | 10 | 4 |
| Unplaced on-board component U | 15 | 6 |
| Quadratic maximum stack, max(0,S-1)^2 | 1.0 | 0.4 |

L is the Euclidean hole-to-hole span times 2.54 mm. S is exact maximum
positive-length vertical segment overlap; endpoints touching do not stack.
S=0 for no wires. Q3 is not electrical quality or percent of theoretical optimum.
Only independently audited PASS boards can qualify for a campaign. Native strict
rules, Q2 geometry measures and solver are unchanged. An unrounded score is a
monotonic transform of the raw construction cost; rounding can introduce ties,
which retain the existing fewer-wires, fewer-cuts, lower-seed tie-break.

## Reproduce on the full local archive

From the repository root:

```bash
python3 scripts/rescore_wr_q3.py --csv ~/Desktop/wr_q3_scores.csv
```

The script validates the ten expected inventory groups, calculates both scores
from all saved JSONs using gui/quality.py, and prints champions, minimum,
median and counts at >=85, >=90 and >=95 per circuit/budget. It does not
run the native solver or write to the historical archive.

## Runtime and target policy

- Open Solved, champion replay, live dashboard and new CSVs use Q3.
- Manifest schema stays 2; quality_version is Q3. Do not resume Q1/Q2
  campaigns or import them into current Pass Two. Existing files remain
  untouched unless the user explicitly authorises a campaign overwrite.
- 85–95, default 90, is the intended future stopping target for an independently
  verified Pass Two/Grand Final board. It is not a guarantee that every design
  can reach the target. Pass One still runs all 200/2,000 selected seeds.
- Pass Two remains import-only; no target-based stopping is implemented yet.
- Construction score does not replace strict electrical or physical auditing.

Regression tests added for Q3, historical Q2, raw cost clipping, Open Solved,
and campaign version. Full GUI regression execution on the Mac is outstanding.
